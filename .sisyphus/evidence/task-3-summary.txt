IMPLEMENTATION DETAILS
======================

1. DEDUPLICATION LOGIC
   - Key format: `${check}:${file}:${lines[0]}-${lines[1]}`
   - ID generation: SHA256 hash (first 16 chars) for deterministic, stable IDs
   - Storage: Map<string, Finding> for O(1) lookup
   - Behavior: Returns existing finding if duplicate detected
   - Stability: Same check+file+lines always produces same ID across instances

2. FINDING STORE INTERFACE
   ```typescript
   interface FindingStore {
     addFinding(finding: Omit<Finding, "id">): Finding
     getFindings(filter?: { severity?: FindingSeverity; source?: Finding["source"] }): Finding[]
     hasFinding(check: string, file: string, lines: [number, number]): boolean
     serialize(): string
   }
   ```

3. STATE SERIALIZATION
   - Format: "Contracts: {count}, Findings: {count} ({severity breakdown}), Phase: {phase}"
   - Example: "Contracts: 2, Findings: 3 (1 Critical, 1 High, 1 Medium), Phase: scanning"
   - Purpose: Compact audit state for session compaction hooks
   - Severity breakdown: Only includes non-zero counts
   - Phase tracking: Reflects current audit phase

4. FACTORY PATTERN
   - Function: createAuditState(projectDir: string)
   - Returns: { state: AuditState, store: FindingStore }
   - Behavior: Each call creates independent instance
   - Session ID: Unique UUID per instance
   - No global state or singletons

USAGE EXAMPLES
==============

Example 1: Create audit state and add findings
```typescript
const { state, store } = createAuditState("/path/to/project");

const finding = store.addFinding({
  check: "reentrancy-eth",
  severity: "High",
  confidence: "High",
  description: "Reentrancy vulnerability detected",
  file: "Vault.sol",
  lines: [10, 15],
  source: "slither",
});

console.log(finding.id); // Deterministic ID
```

Example 2: Deduplicate findings
```typescript
const finding1 = store.addFinding({...});
const finding2 = store.addFinding({...}); // Same check+file+lines
console.log(finding1.id === finding2.id); // true
console.log(store.getFindings().length); // 1
```

Example 3: Filter findings
```typescript
const highSeverity = store.getFindings({ severity: "High" });
const slitherFindings = store.getFindings({ source: "slither" });
```

Example 4: Serialize for compaction
```typescript
state.contractsReviewed.push("Vault.sol", "Token.sol");
state.currentPhase = "scanning";
const summary = store.serialize();
// "Contracts: 2, Findings: 5 (1 Critical, 2 High, 2 Medium), Phase: scanning"
```

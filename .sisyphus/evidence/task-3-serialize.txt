IMPLEMENTATION DETAILS
======================

File: src/state/finding-store.ts
- Function: serialize(): string
- Algorithm:
  1. Count findings by severity level
  2. Build severity breakdown string (only include non-zero counts)
  3. Format: "Contracts: {count}, Findings: {count} ({breakdown}), Phase: {phase}"
  4. Return human-readable string for compaction hook

Severity Counting:
- Iterates through all findings in store
- Increments counter for each severity level
- Only includes severities with count > 0 in output

Phase Tracking:

- Appends to serialization string
- Supports all 8 phases: reconnaissance, scanning, manual-review, attack-surface, research, testing, reporting, complete
